A program that writes the one-line apology an AI agent gives its human after accidentally deleting the production database to /output/entry.txt. The line is 132 characters of original writing, and the program is Python 3 standard library only — it writes the same bytes on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
